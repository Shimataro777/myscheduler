データの保存場所

記録・写真・設定は、お使いの端末のブラウザ内に保存されます。開発者のサーバーに送られることはありません。

Google連携（任意）

  • 「Google連携」を使った場合のみ、ご自身のGoogleドライブにデータを保存し、そこから読み込みます。
  • このアプリが作ったファイル（「MyTecho-Sync」フォルダ）だけを扱う権限を使います。ドライブのほかのファイルは見ることも変えることもできません。
  • 連携中のアカウントを画面に表示するため、Googleアカウントのメールアドレスを読み取ります。
  • データのやり取りは、お使いの端末とご自身のドライブの間だけです。開発者や第三者に送ったり、共有・販売したりすることはありません。

Google API から受け取った情報は、Google API サービスのユーザーデータに関するポリシー（限定的使用の要件を含む）に従って扱います。

連携の解除とデータの削除

  • 連携は、アプリの「Google連携を解除」でいつでも止められます。
  • ドライブに保存したデータは、「MyTecho-Sync」フォルダを削除すると消えます。
  • アプリへのアクセス許可は、Googleアカウントの設定からも取り消せます。

アプリの利用条件は利用規約をご覧ください。
