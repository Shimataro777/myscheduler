# Hibi（ひび）

ひびの記録をつける、じぶんだけの手帳です。
メモ・動画や画像・チェックリスト・リンク・スケジュールを、
その日のならびで見返せます。計画やリスト、フォルダでのまとめもできます。

---

## だいじなこと：書いたものはどこにあるか

**書いたものは、お使いの端末のなかだけに残ります。**
どこかへ送られることはありません。通信もしません。

- iPhoneで書いたものはiPhoneのなかに、iPadで書いたものはiPadのなかに残ります。
  同じ画面を開いても、**端末をまたいで中身は行き来しません。**
- ブラウザの履歴やサイトデータを消すと、いっしょに消えます。
- 機種を変えるときや、ときどきの用心のために、
  メニュー（右上の三本線）→「バックアップ」から書き出しておいてください。
  読み込みも同じ画面からできます。

置き場所を人に見られたくない場合でも、**公開されるのは「アプリの作り」だけで、
書いた中身は公開されません。** 中身は端末のなかにしかないためです。

---

## 公開のしかた（GitHub Pages）

1. GitHub で新しい置き場所（リポジトリ）を作ります。名前は何でもかまいません。
2. この一式をまるごと置きます（`node_modules` と `dist` は要りません）。
   - パソコンから：`git init` → `git add .` → `git commit -m "hibi"` →
     `git remote add origin <あなたの置き場所>` → `git push -u origin main`
   - 画面からでも：GitHub の「Add file」→「Upload files」でフォルダごと放り込めます
3. 置き場所の **Settings → Pages** をひらき、
   **Source** を「**GitHub Actions**」にします。
4. しばらく待つと、**Actions** の欄が緑になり、住所（URL）が出ます。
   その住所をiPhoneのSafariでひらいてください。
5. 共有ボタン →「ホーム画面に追加」で、ふつうのアプリのように使えます。

### ひとに見られたくないとき

- 置き場所を **Private**（非公開）にしたうえで Pages を使うには、
  GitHub の有料の入り方（Pro など）が要ります。
- **Public（公開）のままでも、書いた中身は誰にも見えません。**
  見えるのは、この一式（アプリの作り）だけです。
- どうしても住所を知られたくない場合は、公開せずに
  手もとで `npm install` → `npm run dev` として使う手もあります。

---

## 手もとで動かす

```
npm install
npm run dev
```

出てきた住所を、同じ機械のブラウザでひらきます。
iPhoneから見たいときは `npm run dev -- --host` として、
出てきた住所（192.168… で始まるもの）を同じ回線のiPhoneでひらいてください。

## 中身の置きかた

```
index.html                  起き上がりの絵と、ホーム画面用の決めごと
src/App.jsx                 アプリ本体（これ1枚にすべて入っています）
src/main.jsx                いちばん外側
src/index.css               Tailwind の呼び出しと、ごく少しの決めごと
public/manifest-v1.json     ホーム画面に置いたときの名前と絵
public/icon-*.png           アイコン
make-icon.cjs               アイコンを描き直すための道具
.github/workflows/deploy.yml  置いたら勝手に公開するしくみ
```

### アイコンを描き替えるとき

`make-icon.cjs` の `V` を1つ増やしてから作り直し、
`index.html` と `manifest-v?.json` の名前もそろえてください。
**同じ名前のまま絵だけ替えても、端末に残った古い絵が出続けます。**
なお、iPhoneのホーム画面に置いたアイコンは置いた時点の絵が焼き付くので、
いったん削除して置き直す必要があります。

## 覚えておくとよいこと

- **写真は小さくしてから端末のなかに持ちます。**
  枚数が増えると端末の空きを使うので、ときどきバックアップを取ってください。
- 記録の種類ごとの色、文字の大きさ、動きの有無は
  メニュー →「表示設定」から変えられます。
- タイムラインの記録は、押すとその場で中身がぜんぶ開き、
  下の「とじる」で概要に戻ります。**いくつでも開いたままにできます。**
- 週・月の画面には、その週・その月ぜんたいに付けるメモも置けます。
- 計画の「まとめて登録」は、日付だけでなくリストにも同時に足せます。
- 計画の種類・計画・フォルダは、すべて右下の＋から作ります。
  ひらくとTodayと同じ画面になり、その中の＋から書いた記録は自動でそこに入ります。
- まとめて消したいときは、Todayや「みつける」の右上「選択」から選んで削除できます。
- 名前（Hibi）を変えたいときは、`src/App.jsx` のはじめのほうにある
  `APP_NAME` と、`index.html`・`manifest-v1.json` の名前を書き替えてください。
