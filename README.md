# 4つ並べ

朝の光の中で遊ぶ、7×6 の四目並べ（2人対戦・1台の端末で交互に操作）。
iPhone / iPad / パソコンのブラウザで動きます。

## 遊び方
- 入れたい列をタップして選び、もう一度タップするとチップが落ちます。
- 縦・横・斜めのどれかに自分の色が4つ並んだら勝ち。
- ドラッグで盤を少し傾けて眺められます。ピンチで拡大・縮小。

## GitHub Pages で公開する
1. このフォルダの `index.html` をリポジトリの一番上に置く
2. リポジトリの Settings → Pages → Branch を `main` / `(root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べます

## アップロードするファイル（すべて同じ階層）
index.html / sw.js / manifest.webmanifest / apple-touch-icon.png / icon-192.png / icon-512.png / favicon.png / .nojekyll / README.md

## オフラインで遊ぶ
ネットにつながった状態で一度起動すると、必要なものが端末に保存され、以後は機内モードなどでも1台での対戦ができます（オンライン対戦は除く）。
更新したときは `sw.js` の1行目付近にある `CACHE` の名前（バージョン）も変えてください。

iPhone / iPad では Safari で開き、共有ボタン →「ホーム画面に追加」でアイコンから起動できます。

## オンライン対戦
「順番決め」の画面で「オンライン」を選び、片方が「ルームを作る」、もう片方が表示された4桁のコードを「コードで参加」から入力すると対戦が始まります。
GitHub Pages で公開したページで使えます。通信は無料の公開中継サーバー（EMQX / HiveMQ）を経由します。
