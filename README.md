# My手帳 ― そのまま置いて使える版

**この中のファイルを、GitHub の置き場（リポジトリ）の「いちばん上」にそのまま置いてください。**
組み立て（ビルド）は済んでいるので、何も設定しなくてもページが開きます。

## 置き方

1. GitHub でリポジトリを作る（Public でも Private でも可）
2. この中の**8つのファイルをすべて**、リポジトリの一番上に置く
   （`index.html` がフォルダの中に入ってしまわないように注意）
3. リポジトリの Settings → Pages を開く
4. **Source（ソース）を「Deploy from a branch」**、Branch を **main / (root)** にして Save
5. 1〜2分待つと、`https://ユーザー名.github.io/リポジトリ名/` で開けます

## 入っているもの

| ファイル | なに |
|---|---|
| `index.html` | 入口 |
| `app.js` | アプリ本体（組み立て済み） |
| `app.css` | 見た目 |
| `manifest-v6.json` | ホーム画面に置くための設定 |
| `icon-192-v6.png` `icon-512-v6.png` `apple-touch-icon-v6.png` `favicon.png` | アイコン |

## iPhone / Android で使うとき

ブラウザで開いたあと、**ホーム画面に追加**してください。
- iPhone … 共有ボタン →「ホーム画面に追加」
- Android … メニュー →「ホーム画面に追加」／「アプリをインストール」

**ホーム画面に追加せずタブのまま置いておくと、しばらく使わないだけで記録が消えることがあります。**
ときどきメニューの「バックアップ」から書き出しておいてください。

**ホーム画面に追加すると「My手帳」という名前で並びます。**
前の名前（Hibi）で追加ずみのときは、いちど消してから追加し直してください。

## 記録はどこにある

すべて**その端末の中だけ**です。外には送られません。
別の端末へ移すときは、バックアップを書き出して、移した先で読み込んでください。
